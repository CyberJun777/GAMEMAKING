# 기획서 — 윙볼 (WINGBALL) · 공중 빗자루 구기

> 장르: 3D 3인칭 공중 스포츠 액션 · 1인 vs 컴퓨터 · 브라우저(Three.js)
> 한 줄: 경기장 하늘을 빗자루로 날며 볼을 링에 꽂아 점수를 내고, 경기 중반에 나타나는 빛의 구슬 '골든 오브'를 잡으면 경기가 끝난다.
> ※ 장르·규칙 구조는 공중 구기에서 착안했지만, 이름·팀·경기장·수치는 모두 이 게임만의 오리지널로 설계한다.

## ① 오브젝트 목록

### 선수 (팀당 7명, 총 14명)

| 역할 | 팀당 | 하는 일 | 최고속도 | 가속 | 비고 |
|---|---|---|---|---|---|
| **러너** | 3 | 코멧볼을 패스·슛해 링 득점 | 22 u/s | 18 | **플레이어 기본 조작 역할** |
| **가디언** | 1 | 자기 링 3개 앞을 지키며 슛 막기 | 18 | 20 | 링 앞 반경 14u 안에서만 움직임 |
| **브레이커** | 2 | 배턴으로 스톰스톤을 쳐서 상대에게 날림 | 20 | 16 | AI 전용 |
| **헌터** | 1 | 골든 오브를 쫓아 잡기 | 26 | 22 | Tab으로 플레이어가 전환 가능 |

- 피격(스톰스톤): 1.2초 기절(조작 불가, 천천히 하강) + 들고 있던 코멧볼 떨어뜨림
- 부스트: 최고속도 ×1.5, 스태미나 소모 (아래 ②)

### 볼 / 경기장

| 이름 | 개수 | 역할 | 수치 |
|---|---|---|---|
| **코멧볼** | 1 | 득점용 공. 들고 날거나 패스·슛 | 슛 속도 35~55 u/s (차지), 링 통과 = **+10점** |
| **스톰스톤** | 2 | 스스로 날아다니며 가장 가까운 선수를 들이받는 위험구 | 속도 24 u/s, 브레이커가 치면 40 u/s로 지정 방향 |
| **골든 오브** | 1 | 90초에 등장하는 작고 빠른 빛 구슬. 잡으면 **+100점 & 경기 종료** | 속도 30 u/s(헌터보다 빠름), 0.6~1.2초마다 방향 급변 |
| **링 게이트** | 팀당 3 | 경기장 양 끝, 높이 9 / 14 / 19u, 지름 5u | 링 통과 판정 = 링 평면 교차 + 중심 거리 < 2.5u |
| **경기장** | 1 | 타원형 160 × 90u, 높이 상한 45u, 바닥 아래로 못 감 | 경계 밖으로 나가면 부드럽게 밀려 돌아옴 |
| **관중석** | 1 | 타원 둘레 스탠드 + 관중(인스턴싱) | 시각용, 충돌 없음 |

팀: **청록 팀(플레이어)** vs **주황 팀(컴퓨터)** — 서로 보색이라 공중에서 바로 구분된다.

## ② 자원 · 경기 규칙 (이 게임의 '경제')

- **점수**: 링 득점 +10 / 골든 오브 포획 +100 & 즉시 종료 → 점수 높은 팀 승리 (동점이면 골든 오브를 잡은 팀 승)
- **스태미나**: 최대 100. 부스트 중 초당 −25, 미사용 시 초당 +12 회복(사용 후 0.8초 딜레이). 0이면 부스트 불가
- **슛 차지**: 좌클릭 누르는 시간 0~1초 → 속도 35~55, 정확도 오차 6°→2°
- **볼 소유**: 빈 코멧볼에 2u 이내로 접근하면 자동 획득. 소유자는 최고속도 ×0.9
- **스틸**: 우클릭 태클 — 볼 소유 상대 3u 이내, 성공률 55%(정면) / 75%(측후면), 쿨다운 2초
- **득점 후 리셋**: 실점한 팀 가디언이 코멧볼을 받아 자기 링 앞에서 재개
- **경기 시간 보장**: 6분이 지나도 골든 오브를 못 잡으면 골든 오브 속도가 분당 −15%씩 줄어 결국 잡힌다 (무한 경기 방지). 9분 하드 리밋 → 점수로 판정

## ③ 컴퓨터(AI) 행동 — 구체 수치

공통: 판단 주기 0.25초(쉬움 0.4 / 어려움 0.15), 속도 배수 쉬움 0.85 / 보통 1.0 / 어려움 1.1

| 역할 | 행동 규칙 |
|---|---|
| 러너(볼 소유) | 상대 링까지 30u 이내 & 앞 8u에 수비 없음 → 슛. 막혔으면 더 앞에 있는 열린 동료(패스 경로 3u 안에 상대 없음)에게 패스. 둘 다 아니면 링 방향으로 전진, 정면 수비 있으면 좌우·상하로 6~10u 우회 |
| 러너(볼 없음, 공격) | 볼 소유 동료 앞쪽 15~25u 빈 공간으로 침투 (서로 8u 이상 간격 유지) |
| 러너(수비) | 가장 가까운 1명이 볼 소유자 압박(태클 시도), 나머지 2명은 패스 경로 차단 위치 |
| 가디언 | 볼과 3개 링의 중심을 잇는 선 위, 링에서 6u 앞에 위치. 슛 감지 시 예측 궤적으로 반응(반응 지연 0.2초) — 막을 확률 ≈ 보통 40% |
| 브레이커 | 스톰스톤이 10u 안에 오면 → 상대 볼 소유자(없으면 상대 헌터) 방향으로 타격. 평소엔 자기 볼 소유자 근처 호위 |
| 헌터 | 골든 오브 등장 전: 높은 곳(30u)에서 선회. 등장 후: 골든 오브의 0.4초 뒤 예측 위치로 추격. 포획 판정 = 1.5u 이내 0.3초 유지 |
| 스톰스톤 | 3초마다 가장 가까운 선수(양 팀 무관)를 목표로 재지정, 맞히면 반대 방향으로 튕김 |

난이도별 기대 결과: 보통 난이도에서 AI는 6분 동안 3~6골 득점 (밸런싱 목표).

## ④ 조작 체계

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 시선/진행 방향 (Pointer Lock, 클릭하면 잠김, Esc 해제=일시정지) |
| W / S | 전진 가속 / 감속·후진 |
| A / D | 좌우 평행이동(기울며 미끄러짐) |
| Space / C | 상승 / 하강 |
| Shift (홀드) | 부스트 (스태미나 소모) |
| 좌클릭 (홀드→놓기) | 볼 있으면 슛(차지) · 헌터일 땐 잡기 시도(가까울 때) |
| E | 시선 방향에 가장 가까운 동료에게 패스 |
| 우클릭 | 태클(스틸) |
| Tab | 러너 ↔ 헌터 전환 (골든 오브 등장 후에만 의미 있음, 전환 쿨다운 3초) |
| Q | 볼/골든 오브 쪽으로 카메라 스냅 |
| P / Esc | 일시정지 |

- 카메라: 3인칭 추적(뒤 7u, 위 2.5u), 속도 빠를수록 FOV 70→85, 부딪힘 없이 부드러운 보간
- ⚠️ 키 충돌 점검: 카메라는 마우스 전용이라 WASD와 명령키(E/Q/Tab)가 겹치지 않는다. Tab은 브라우저 포커스 이동을 막도록 `preventDefault`

## ⑤ 화면 구성 (UI)

- **상단 중앙**: 스코어보드 `청록 30 : 20 주황` + 경기 시계
- **좌하단**: 스태미나 바, 현재 역할(러너/헌터), 볼 소유 표시
- **우하단**: 미니맵 (경기장 위에서 본 타원 + 선수 점(팀색) + 코멧볼(흰색) + 스톰스톤(검정) + 골든 오브(노랑, 등장 후))
- **중앙**: 조준점 + 슛 차지 원형 게이지, 패스 대상 동료 하이라이트
- **화면 가장자리 화살표**: 화면 밖의 코멧볼·골든 오브 방향 표시
- **이벤트 배너**: "GOAL!", "골든 오브 등장!", "기절!" (1.5초)
- **시작 화면**: 제목 + 난이도 선택 + 조작 설명 / **종료 오버레이**: 승리·패배 + 최종 점수 + 다시하기

## ⑥ 완료 기준 체크리스트 ★

각 항목 = self-check 테스트 1개 (H = headless 시뮬레이션, B = 브라우저)

**비행·조작**
- [ ] (B) W를 1초 누르면 플레이어가 바라보는 방향으로 이동하고, 최고속도 22u/s를 넘지 않는다

- [ ] (H) 선수는 경기장 경계(타원·높이 45·바닥 0) 밖으로 나가지 않는다 (60초 무작위 비행 후 위치 검사)
- [ ] (B) Tab으로 러너↔헌터 전환이 되고 3초 쿨다운이 지켜진다

**볼·득점**
- [ ] (H) 빈 코멧볼에 2u 이내로 접근하면 소유권을 얻는다
- [ ] (H) 링을 정면으로 통과한 슛은 +10점, 링 테두리 밖으로 지나간 슛은 0점이다
- [ ] (H) 득점 후 실점 팀 가디언이 볼을 가진 상태로 재개된다
- [ ] (H) 태클 성공 시 소유권이 넘어가고, 쿨다운 2초 안엔 다시 태클할 수 없다
- [ ] (B) E 패스 시 볼이 시선에 가장 가까운 동료에게 날아가 그 동료가 받는다

**AI**
- [ ] (H) AI 러너들이 플레이어 개입 없이 6분 시뮬레이션 동안 실제로 슛을 1회 이상 하고 득점한다
- [ ] (H) AI 가디언이 링 앞 반경 14u 밖으로 나가지 않는다
- [ ] (H) 스톰스톤이 60초 동안 최소 1회 선수를 맞히고, 맞은 선수는 1.2초 기절 + 볼을 떨어뜨린다
- [ ] (H) 브레이커가 근처 스톰스톤을 쳐서 상대 쪽으로 날린다 (60초 내 1회 이상)
- [ ] (H) 정지 상태로 두어도 AI끼리 경기가 끝까지 진행된다 (교착/멈춤 없음 — 30초 이상 아무도 볼에 접근 안 하는 구간 0회)

**골든 오브·경기 종료**
- [ ] (H) 골든 오브는 90초 전에는 없고, 90초에 등장한다
- [ ] (H) 헌터가 골든 오브에 1.5u 이내로 0.3초 머물면 +100점과 함께 경기가 즉시 끝난다
- [ ] (H) 아무도 못 잡아도 9분 안에 경기가 반드시 끝난다 (골든 오브 감속 + 하드 리밋)
- [ ] (H) 종료 시 점수가 높은 팀이 승자로 판정된다 (동점 → 골든 오브 포획 팀)
- [ ] (B) 종료 시 승리/패배 오버레이와 최종 점수, 다시하기 버튼이 뜨고 다시하기가 동작한다

**화면·품질**
- [ ] (B) 스코어보드·시계·스태미나·미니맵이 실제 게임 상태와 일치하게 갱신된다
- [ ] (B) 화면 밖의 코멧볼/골든 오브 방향으로 가장자리 화살표가 표시된다

## 기술 구성 (기본값)

- 단일 `index.html` + ES 모듈, 빌드 도구 없음. Three.js는 `vendor/`에 `three.module.js` + `three.core.js` 둘 다 직접 포함
- 폴더: `js/config.js`(모든 수치) · `js/sim/`(경기 로직: match, physics, ai, balls — DOM 무관) · `js/render/` · `js/input.js` · `js/ui.js` · `textures/` · `css/`
- `js/sim/`은 Node에서 그대로 돌아가게 → headless 테스트 `tests/sim.test.mjs`
- 텍스처: 힉스필드 미연결이므로 절차적 생성 스크립트 사용 (필드 잔디 재질은 레시피 추가 필요)

## 변경 이력 (개발·검수 중 반영 — 승인 후 추가된 규칙)

| 항목 | 변경 | 이유 |
|---|---|---|
| 링 앞 금지 구역 | 상대 링 평면 16u 안으로 볼을 들고 들어가면 상대 가디언 볼 | 링 바로 앞 빈 골대 슛으로 득점률 80% → 32% |
| 가디언 | 슛 감지 시 매 스텝 반응, 블록 반경 3.2u | 판단 주기(0.25s)로는 슛에 항상 늦음 |
| AI 슛 정확도 | 난이도별 추가 오차 10° / 7.5° / 6° | 밸런스 목표(AI 6분당 3~6골) → 실측 4.8~5.0골 |
| 골든 오브 | 22% 확률로 잠깐 맴돌기(속도 25%), 도주 반경 18u | 원안대로면 헌터가 거의 못 잡음 → 경기 중앙값 5.3분 |
| 스태미나 | 0이 되면 25까지 회복 전 부스트 불가(탈진) | Shift 유지 시 부스트가 깜빡이며 재가동하던 문제 |
| 스톰스톤 | 유도 가속 30 → 12 | 피격 빈도 과다(3초당 1회 → 6.5초당 1회) |
| 키보드 슛 | F 키(홀드→놓기)로도 슛 | 마우스 없이도 플레이 가능 |
