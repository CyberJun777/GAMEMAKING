# 기획 변경안 — 오리지널 몬스터 테마 (폐기: design/plan-v2.md로 대체됨)

> 상태: **제안**. 승인 전에는 코드를 바꾸지 않는다. 승인되면 `design/plan.md`에 반영하고 구현한다.
> 원칙: 포켓몬 등 기존 IP의 이름·캐릭터·이미지는 쓰지 않는다. 가져오는 것은 **게임 방식**(속성, 진화, 도감)뿐이고 생물 15종은 전부 새로 디자인한다.

## 0. 무엇이 바뀌나 (한 줄 요약)
"기계/생체/비전 타워" → **"번개/서리/불꽃 속성의 수호수(생물)"**. 합성은 **진화**로 연출한다.
결과 속성이 랜덤이라 진화하면서 속성이 바뀔 수도 있다(**변이**). 이것이 "무엇으로 변할지 모르는 생물" 콘셉트다.

## 1. 범위 선택 (둘 중 하나 승인)
| 안 | 내용 | 규칙 변화 | 밸런스 영향 |
|---|---|---|---|
| **A. 겉모습만 (추천)** | 이름·색·3D 실루엣·UI 문구·연출을 몬스터 테마로 | 없음 (수치 그대로) | 없음. 성실 봇 6/6 유지 확인만 |
| B. A + 속성 상성 | 적에게도 속성을 줌 (라운드마다 번개→서리→불꽃 순환). 유리 속성 피해 ×1.5, 불리 ×0.75 | 새 규칙 1개 | 재밸런싱 필요 (`config.js`) |

- 상성 순환(B안): 번개 → 서리 → 불꽃 → 번개 (화살표 쪽에 강함). HUD에 "이번 라운드 적 속성" 표시를 추가한다.

## 2. 속성 3개 (현재 진영 → 새 속성, 전투 성격은 그대로)
| 현재 | 새 속성 | 전투 성격 (그대로) | 몸체 색 (안) |
|---|---|---|---|
| 기계 | **번개** | 사거리 길고 단일·관통 강함 | 노랑 `#f2cf3a` |
| 생체 | **서리** | 공속 빠름 + 둔화(냉기) + 오라 | 청백 `#a9c7ff` |
| 비전 | **불꽃** | 범위·연쇄 | 주홍 `#ff6a3d` |

- ⚠ 색 충돌 점검: 서리 청백이 희귀 등급 하늘색(`#5fd0ff`)과, 불꽃 주홍이 전설 등급 주황(`#ff9a2e`)과 가깝다.
  → 승인 시 대비 테스트(몸체색 ↔ 등급색 색차 하한)를 추가하고, 필요하면 등급색이 아니라 **속성색**을 조정한다.

## 3. 수호수 15종 (등급 = 진화 단계, 능력치는 현재 표 그대로)
| 단계(등급) | 번개 | 서리 | 불꽃 |
|---|---|---|---|
| 1 (일반) | **콩전구** 전구 껍데기 달팽이 | **눈꼬물이** 서리 애벌레 | **불씨깨비** 작은 불꽃 도깨비 |
| 2 (희귀) | **번쩍매** 피뢰침 깃털 매 (드론처럼 떠 있음) | **서리거미** 얼음 다리 거미 | **화염방울** 떠다니는 불 구슬 + 위성 불씨 |
| 3 (영웅) | **뇌창사슴** 평행한 레일 뿔 사슴 (관통) | **설화꽃** 냉기 장판을 피우는 얼음꽃 | **유성거북** 등에 운석을 진 거북 |
| 4 (전설) | **천둥고래** 등에 안테나 달린 하늘고래 (사거리 전체) | **빙하여왕** 날개 달린 얼음 여왕 | **폭염핵** 고리 두른 불꽃 심장 |
| 5 (신) | **뇌운룡** 구름을 두른 용 | **설원수** 얼음 세계수 (오라) | **태양새** 불꽃 날개 새 |

- 실루엣은 이번에 만든 15종 InstancedMesh 구조(몸체=속성색, 장식=등급색)를 그대로 쓰고 모양만 생물로 바꾼다.
  성능 예산 영향 없음 (종당 ≤ 1,500 tri, draw call 동일).
- 적 몬스터: "탁해진 결정 덩어리"로 이름·색만 정리 (모양 유지).

## 4. UI·연출 문구
| 현재 | 변경 |
|---|---|
| 뽑기 | **소환** (D, 광물 50 그대로) |
| 합성 | **진화** (F 그대로). 속성이 바뀌면 토스트 "변이! 서리 → 불꽃" |
| 보유 유닛 | **수호수 도감** (15칸, 처음 얻은 종은 "NEW" 표시) |
| 진영 업그레이드 | **속성 강화** (1/2/3 그대로) |
| 합성 연출 | 진화 빛기둥 + 실루엣이 커졌다 작아지는 "변신" 0.4초 |

단축키·수치·승패 조건은 전부 그대로다.

## 5. 완료 기준 추가 (승인 시 테스트로 변환)

- [ ] 32. 몸체 속성색과 등급색의 색차가 기준 이상이다 (5등급 × 3속성)
