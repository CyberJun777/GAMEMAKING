# 기획서 — 「랜덤 타워 디펜스: 프리즘 링」 (가제)

> 승인: 2026-11-17 (합성 = 같은 유닛 2기). 아래 수치는 `self-check` 밸런싱 후 값 — 실제 값의 원본은 `js/config.js`.

> 장르 레퍼런스: 스타2 아케이드 「랜덤타워디펜스(랜타디)」의 **게임 방식**(랜덤 뽑기 · 등급 합성 · 진영 업그레이드 · 라운드 보스).
> 유닛·세계관·그래픽은 전부 오리지널 (스타2 유닛/종족 이름·모델 사용 안 함).
> 모드: **싱글 플레이 vs 컴퓨터 웨이브**, 실시간, 3D 쿼터뷰(Three.js).

## 0. 한 판의 흐름 (종이 위에서 굴려보기)
1. 시작: 광물 200 / 가스 100. 보드 중앙에 빈 칸들, 바깥 사각 고리 길로 몬스터가 **끝없이 빙글빙글 돈다**(골인 지점 없음).
2. 광물 50으로 **[뽑기]** → 랜덤 유닛 1기가 빈 칸에 생긴다 (대부분 일반 등급).
3. **같은 유닛 2기 → [합성]** → 한 등급 위의 랜덤 유닛 1기.
4. 가스로 진영별 공격력 업그레이드. 10라운드마다 보스. 길 위 몬스터가 **70마리**를 넘으면 즉시 패배.
5. 40라운드 보스를 잡으면 승리. 한 판 약 30~35분.

### 진영 3개 (가스 업그레이드 단위)
- **기계(Mech)** — 사거리 길고 단일 공격 강함. 색 포인트: 강철 청색
- **생체(Bio)** — 공격 속도 빠름 + 둔화·독 디버프. 색 포인트: 초록 생체광
- **비전(Arcane)** — 범위(스플래시)·연쇄 공격. 색 포인트: 보라 결정

### 유닛 15종 (등급 5 × 진영 3) — 능력치 골격 (밸런싱은 검수 단계에서)

- 모든 공격은 **진영 업그레이드 배율**과 **물리/마법 구분 없이** 적 방어력만큼 감소(최소 피해 1).

### 몬스터

|---|---|---|---|---|---|
| 일반 몬스터 | 매 라운드 40마리 | `25 × 1.215^(R-1)` (R40 ≈ 50만) | `floor(R/4)` | 1.6 | 광물 1 |
| 보스 | R10/20/30/40, 1마리 | 그 라운드 일반 체력 × 3.5 | 일반 방어 × 3 | 0.9 | 결정 1 + 광물 100 |

## ② 자원 · 경제 규칙
| 자원 | 얻는 법 | 쓰는 곳 |
|---|---|---|
| **광물** | 시작 200, 몬스터 처치 1, 라운드 종료 보너스 `20 + 2×R`, 보스·미션·업적 보상 | 뽑기 50 (고정), 가스 구매 |
| **가스** | 시작 100, 라운드 종료 `10 + R`, 미션 보상, 결정 환전, 광물 환전 | 진영 업그레이드 |
| **결정** | 보스 처치 1개 | 가스 250으로 환전 (언제든) |

- **환전:** 광물 100 → 가스 60, 가스 100 → 광물 60 (양방향 손해. 원본의 "가스 판매" 대응)
- **진영 업그레이드:** 진영별 0~30레벨. 1레벨당 그 진영 유닛 공격력 **+12%**. 비용 `20 + 10×현재레벨` 가스.
- **판매:** 유닛 판매 시 ①의 판매가만큼 광물 환급.
- **업적 (1회성 광물 보상):**
  | 업적 | 조건 | 보상 |
  |---|---|---|
  | 물량전 | 일반 유닛 8기 동시 보유 | 광물 200 |
  | 첫 영웅 | 영웅 등급 첫 획득 | 광물 150 |
  | 영웅 수집가 | 영웅 7기 획득(누적) | 광물 500 |
  | 전설 수집가 | 전설 6기 획득(누적) | 광물 1000 |
  | 삼위일체 | 같은 등급에서 3진영을 동시 보유 | 광물 300 |
  | 학살자 | 누적 처치 500 / 2000 / 5000 | 광물 200 / 500 / 1000 |
- **보유 상한:** 배치 칸 204칸이 곧 유닛 상한. 빈 칸이 없으면 뽑기 버튼 비활성.

## ③ 적(웨이브) 행동 — 구체적 숫자
| 항목 | 값 |
|---|---|
| 총 라운드 | 40 |
| 라운드 길이 | 35초 고정 (생성 20초 + 휴식 15초). 이전 라운드 몬스터가 남아 있어도 다음 라운드는 시작됨 |
| 생성 | 라운드 시작 후 20초 동안 0.5초 간격으로 40마리 |
| 이동 | 고리 길을 시계 방향으로 무한 순환. 경로는 고정 웨이포인트(모서리 4개) |
| 보스 라운드 | R10/20/30/40: 일반 몬스터 대신 보스 1마리, **제한 시간 90초** (보스가 고리를 약 1.5바퀴) |
| 보스 실패 | 제한 시간 안에 못 잡으면 **목숨 −1**, 보스는 사라짐. 시작 목숨 **3**. 단 **R40 최종 보스를 놓치면 즉시 패배** |
| 패배 조건 | ① 길 위 일반 몬스터 수 ≥ **70** (즉시 패배) ② 목숨 0 |
| 승리 조건 | R40 보스 처치 |
| 미션 보스 | 플레이어가 버튼으로 소환. 각 미션 쿨타임 90초. 제한 시간 60초 (실패해도 벌칙 없음, 보상만 없음). 동시 1마리만 |
| 첫 몬스터 | 게임 시작 5초 후 (그 사이 첫 뽑기) |

> 검증용 기대치: 뽑기만 성실히 하고 업그레이드를 고르게 찍으면 R10 보스는 영웅 2~3기로, R20은 전설 1기+, R30·40은 신 1기 이상 필요하도록 맞춘다 (원본 공략의 진행 곡선과 동일한 체감).

## ④ 조작 체계
| 입력 | 동작 |
|---|---|
| 좌클릭 | 유닛 1기 선택 |
| 좌드래그 | 박스로 여러 기 선택 |
| 더블클릭 | 화면 안의 같은 종류 유닛 전체 선택 |
| 우클릭(빈 칸) | 선택한 유닛 1기를 그 칸으로 이동 (여러 기면 근처 빈 칸에 순서대로) |
| **D** | 뽑기 |
| **F** | 선택한 유닛 합성 (같은 유닛이 2기 이상 있을 때) |
| **G** | 선택한 유닛 판매 |
| **1 / 2 / 3** | 기계 / 생체 / 비전 업그레이드 |
| **Z / X / C** | 미션 보스 1 / 2 / 3 소환 |
| Space | 일시정지 |
| Tab | 배속 1× ↔ 2× |
| 방향키 | 카메라 이동 (보드 바깥으로는 제한) |
| 휠 | 줌 (최소/최대 제한) |

- ⚠️ 카메라는 **방향키만** 쓴다. WASD는 아예 쓰지 않아서 단축키(D·F·G·Z·X·C)와 겹치지 않는다.
- 시점: 고정 각도 쿼터뷰(약 55° 내려다봄). 엣지 스크롤 없음 (보드가 한 화면에 거의 다 들어오는 크기라서 필요 없음).

| 오버레이 | 승리 / 패배(사유 표시) + 통계(라운드, 처치 수, 최고 등급) + [다시 하기] |

## ⑥ 완료 기준 체크리스트 ★
각 항목 = `self-check`의 테스트 1개.

**경제·뽑기**
- [ ] 1. 광물 50 이상일 때 뽑기를 누르면 광물이 50 줄고 빈 칸에 유닛 1기가 생긴다
- [ ] 2. 광물이 50 미만이거나 빈 칸이 없으면 뽑기가 안 되고 광물도 그대로다
- [ ] 3. 뽑기 10,000회 시뮬레이션에서 등급 비율이 일반 82 / 희귀 15 / 영웅 3% (±1.5%p)이다
- [ ] 4. 같은 유닛 2기를 합성하면 2기가 사라지고 한 등급 위 유닛 1기가 생긴다
- [ ] 5. 서로 다른 유닛 2기, 또는 신 등급 유닛은 합성되지 않는다
- [ ] 6. 판매하면 유닛이 사라지고 등급별 판매가만큼 광물이 는다
- [ ] 7. 진영 업그레이드 1회 → 가스가 비용만큼 줄고, 그 진영 유닛의 실제 피해가 12% 증가한다 (다른 진영은 그대로)
- [ ] 8. 환전(광물↔가스, 결정→가스)이 정해진 비율로 동작한다
- [ ] 9. 업적 6종이 조건을 만족하는 순간 정확히 1번씩 보상을 준다

**웨이브·전투**
- [ ] 10. 시작 5초 후 몬스터가 나와 고리 길을 시계 방향으로 끝없이 돈다 (한 바퀴 후 출발점을 지나도 계속 이동)
- [ ] 11. 라운드마다 정확히 40마리가 나오고, 35초마다 라운드 번호가 오른다
- [ ] 12. 유닛이 사거리 안의 몬스터를 공격하고, 몬스터 체력이 줄며, 0이 되면 사라지고 광물 +1
- [ ] 13. 스플래시·연쇄·둔화·독·오라가 각각 기획대로 동작한다 (범위 안 여러 마리 피해, 이동 속도 감소 등)
- [ ] 14. 방어력이 피해를 깎고, 피해가 최소 1은 들어간다
- [ ] 15. R10/20/30/40에 보스가 나오고, 처치하면 결정 1 + 광물 100
- [ ] 16. 보스를 90초 안에 못 잡으면 목숨이 1 줄고 보스가 사라진다
- [ ] 17. 미션 보스를 소환할 수 있고, 처치 보상과 90초 쿨타임이 동작한다

**승패**
- [ ] 18. 길 위 몬스터가 70마리가 되는 순간 패배 화면이 뜬다 (아무것도 안 하는 시나리오)
- [ ] 19. 목숨이 0이 되면 패배 화면이 뜬다
- [ ] 20. R40 보스를 잡으면 승리 화면이 뜬다
- [ ] 21. **성실 플레이 봇**(광물 생기면 뽑기 → 합성 가능하면 합성 → 남는 가스로 업그레이드)이 R40까지 클리어한다. **방치 봇**은 R5 이전에 진다 (난이도가 깰 수 있으면서 쉽지 않은지 확인)

**조작·화면**
- [ ] 22. 클릭으로 1기 선택, 드래그 박스로 여러 기 선택, 선택 정보 패널이 갱신된다
- [ ] 23. 선택한 유닛을 빈 칸에 우클릭하면 이동하고, 길이나 이미 찬 칸에는 이동하지 않는다
- [ ] 24. 단축키 D/F/G/1/2/3/Z/X/C/Space/Tab이 각각 동작하고, 방향키는 카메라만 움직인다
- [ ] 25. 상단 바·몬스터 게이지·도감 숫자가 실제 게임 상태와 일치한다
- [ ] 26. 승리/패배 화면에서 [다시 하기]를 누르면 처음 상태로 돌아간다
- [ ] 27. 부팅부터 승리/패배까지 브라우저 콘솔에 에러·경고가 0건이다
- [ ] 28. 최악 장면에서 성능 예산(아래)을 지킨다

## ⑦ 성능 상한
| 항목 | 상한 | 지키는 법 |
|---|---|---|
| 목표 프레임 | 60fps (최악 장면 55+) | |
| 최악 장면 | 유닛 120기 + 몬스터 70 + 보스 2 + 투사체 300 + 파티클 300 + 2× 배속 | 검수 때 이 장면을 강제로 만들어 측정 |
| Draw call | **≤ 200** | 몬스터·투사체·파티클·같은 종류 유닛은 `InstancedMesh`. 유닛 15종 × (몸체 진영색 + 장식 등급색) = 30개 + 받침·후광. 재질 공유 (측정 93) |
| 삼각형 | ≤ 40만 | 유닛은 로우폴리 실루엣 (종당 ≤ 1,500 tri) |
| 텍스처 | 지형 2~3종 + 길 1종 + 특수 1종, 각 1024² | `game-texture` 단계에서 |
| 그림자 | 방향광 1개, 2048 맵, 보드 크기에 맞춘 고정 범위 | |
| 시뮬레이션 | 30Hz 고정 타임스텝, 틱당 ≤ 2ms (최악 장면) | 몬스터 ≤ 72라 전수 검색으로 충분 (측정 0.04ms) |

## ⑧ 기술 구성
- 단일 `index.html` + ES 모듈, 빌드 도구 없음. `python3 -m http.server`로 실행.
- Three.js를 `vendor/`에 직접 넣음 (`three.module.js` + `three.core.js` 둘 다).
- 폴더:
  ```
  index.html
  css/style.css
  js/config.js     — 유닛·몬스터·경제 수치 전부 (밸런싱은 여기만 수정)
  js/sim/          — 시뮬레이션 (DOM·Three 렌더 의존 없음 → Node 헤드리스 테스트)
     game.js(유닛·경제·업적)  board.js  waves.js  combat.js  rng.js
  js/render/       — Three.js 씬·인스턴싱·이펙트
  js/ui/           — HUD·패널·오버레이
  js/input.js
  tests/           — Node 시뮬레이션 테스트 + Playwright 브라우저 테스트
  textures/
  ```
- 난수는 **시드 고정 RNG**를 써서, 테스트와 버그 재현이 같은 결과를 내게 한다.
