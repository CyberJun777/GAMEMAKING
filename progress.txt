# progress — 프리즘 링 (랜덤 타워 디펜스)

## 반복 1 — 시뮬레이션 코어 + 밸런스
- [고침] 기획서의 칸 수 계산 오류: 18×18 보드는 안쪽이 12×12가 아님 → 16×16 보드(안쪽 144 + 테두리 60 = 204칸)로 확정.
- [고침] 테스트 봇이 게임 종료 후 결정 환전을 무한 반복 → 상태 확인 + 실패 시 탈출.
- [밸런스] 첫 측정: 성실 봇이 몬스터를 거의 안 흘리고 압승. R10에 신 등급 7기.
  원인 ① "2기 합성"이라 신 1기 = 뽑기 16회(광물 800)뿐인데 수입이 너무 많음
       ② 전설·신 화력이 등급당 4~5배로 폭증 ③ 업적 보상 과다
  → 처치 보상 2~5 → 1, 라운드 보너스 60+5R → 20+2R, 신·전설 화력을 등급당 ~2.8배로 하향,
    업적(영웅 수집 800→500, 전설 수집 2000→1000).
- [밸런스] 가스 부족으로 업그레이드가 거의 안 오름 → 라운드 종료마다 가스 10+R 지급.
- [밸런스] 체력 성장률 스윕(1.17~1.33) × 보스 배율(60/25/12/8/6/5) × 미션 체력 배율.
  최종: 체력 25×1.215^(R-1), 보스 = 일반×6, 미션 체력 ×3.
  결과: 성실 봇 6/6 승리, 최종 보스 처치에 70초 중 23~64초 소요 (빠듯함). 방치 봇은 R2에 패배.
- 시뮬레이션 테스트 24/24 통과 (완료 기준 1~21 + 보드·재현성·이동).

## 반복 2 — 렌더·UI·입력 + 브라우저 검수 (Playwright, SwiftShader)
- [고침] 바닥에 대각선 얼룩: 받침 윗면과 바닥판이 같은 y=0 → z-fighting. 받침을 0.01 내림.
- [고침] ★실제 버그: 버튼을 마우스로 누른 뒤 Space(일시정지)를 누르면 포커스된 버튼이 다시 눌려
  몰래 뽑기가 됨. → 모든 버튼 tabIndex=-1 + mousedown preventDefault. 회귀 테스트 추가.
- [고침] 테스트 쪽 실수: 최악 장면에 몬스터를 72마리 깔아 한도(70)로 즉시 패배 → 이후 테스트 연쇄 실패.
  잔여 몬스터 정리 + 일반 68 + 보스 2 = 70마리로 수정, "게임이 계속 진행 중"도 단언.
- 단축키는 e.code(물리 키)로 처리 → 한글 입력 상태에서도 D/F/G가 동작.
- 브라우저 테스트 16/16 통과 (완료 기준 18~20 오버레이, 22~28, 회귀 1건).
